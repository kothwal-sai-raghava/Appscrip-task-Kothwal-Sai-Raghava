# Appscrip PLP Assignment

## Objective
Implementation of Product Listing Page based on the provided Figma design using Next.js with Server Side Rendering (SSR).

## Tech Stack
- Next.js (React)
- HTML5 & CSS3
- Server Side Rendering (SSR)
- Fake Store API (optional)
- No UI libraries (pure CSS)

## Features
- Pixel-aligned PLP UI
- Responsive (Desktop / Tablet / Mobile)
- SEO optimized (meta tags, H1/H2, alt text, schema)
- Minimal DOM & clean code structure
